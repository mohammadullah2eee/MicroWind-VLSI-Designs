# MicroWind-VLSI-Designs

A collection of VLSI circuit designs developed using **MicroWind**, covering MOS transistor structures, basic logic gates, combinational circuits, sequential circuits, and advanced digital systems.

This repository provides downloadable and editable `.msk` layout files along with corresponding YouTube video tutorials and demonstrations. It is intended to help students, electronics enthusiasts, and VLSI learners explore practical circuit design.

## Project Overview

The primary objective of this repository is to organize and share practical VLSI designs created using MicroWind. These designs can be used for academic learning, circuit analysis, experimentation, and further development.

### Repository Highlights

- NMOS, PMOS, and CMOS transistor designs.
- Basic digital logic gates.
- Arithmetic and combinational logic circuits.
- Sequential circuits and flip-flops.
- Advanced digital systems, including ALU, barrel shifter, and crossbar switch.
- Directly downloadable MicroWind `.msk` design files.
- Corresponding YouTube tutorials and demonstrations.

## Software Requirements

To open and work with the designs, you need:

- **MicroWind:** VLSI layout design and simulation software.
- A compatible MicroWind installation that supports `.msk` files.
- A Windows computer running the supported software environment.

## How to Download and Open a `.msk` File in MicroWind

Follow these instructions to download and open any design file available in this repository.

### Step 1: Download a Design File

1. Browse the appropriate circuit category in this README.
2. Find the circuit you want to explore.
3. Click the corresponding **Download** link.
4. Save the `.msk` file to your preferred location.

Alternatively, you can download the entire repository by clicking the green **Code** button and selecting **Download ZIP**.

### Step 2: Launch MicroWind

1. Open the MicroWind application on your computer.
2. Wait for the main MicroWind interface to load completely.

### Step 3: Open the Downloaded Design

1. Click **File** from the top menu bar.
2. Select **Open** from the dropdown menu.
3. Navigate to the folder where you saved the downloaded `.msk` file.
4. Select the desired `.msk` file.
5. Click **Open**.

### Step 4: View and Explore the Design

The selected circuit layout should now appear in the MicroWind workspace.

You can inspect the transistor arrangement, layout geometry, and circuit connections.

### Step 5: Simulate the Circuit

If you want to investigate its operation, use the available simulation and analysis features in your installed MicroWind version. Configure the input signals and simulation settings according to the circuit you are studying.

*Note: Menu names and simulation options may vary between MicroWind versions.*
